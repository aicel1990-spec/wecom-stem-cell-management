# 企业微信干细胞动员与采集管理系统技能

这是一个可复用的 Codex skill，用于设计、配置、验证和迁移企业微信智能表格中的干细胞动员与采集管理流程。

## 适用场景

- 依据 `5天方案`、`14天方案` 预测采干日期
- 管理动员开始日期、计划采干时间、负责医生和采集状态
- 对每日最多 3 人的采干容量进行提示
- 配置采前 3 天、采前 1 天提醒
- 建立临床工作台、管理视图、日历和仪表盘
- 用 20 名合成患者做压力测试和迁移验收

## 安装

将本目录复制到 Codex 的 skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R wecom-stem-cell-management ~/.codex/skills/
```

在 Codex 对话中按名称调用：

```text
$wecom-stem-cell-management
```

如果你的 Codex 使用自定义 skills 路径，请把目录复制到该路径下，并重启或刷新技能索引。

## 重要边界

本技能是流程与配置指南，不是医疗决策工具。临床判断仍由负责医生完成。

仓库不包含企业微信账号、访问令牌、患者真实身份信息、真实智能表格数据或租户专属配置。测试应使用合成记录。企业微信原生智能表格无法强制执行的规则，只能显示预警；真正的硬性限制需要企业微信应用、API 或管理员支持。

## 迁移原则

迁移到另一台电脑或另一个企业微信租户时，应复制技能目录后，在目标租户重新配置人员、权限、群聊、自动化接收人和日历。技能本身不会自动迁移租户数据。
