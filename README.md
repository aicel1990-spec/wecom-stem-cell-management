# 企业微信干细胞动员与采集管理系统技能

这是一个可复用的 Codex skill，用于设计、配置、验证和迁移企业微信智能表格中的干细胞动员与采集管理流程。

## 内容

- 字段与日期公式设计
- 5天方案、14天方案
- 采干容量最多3人的预警逻辑
- 临床工作台、管理视图、日历和仪表盘
- 采前3天、采前1天提醒
- 企业微信迁移流程
- 20名模拟患者压力测试与验收清单

## 使用

将 `wecom-stem-cell-management` 文件夹复制到 Codex 的 `~/.codex/skills/` 目录，然后在对话中使用：

```text
$wecom-stem-cell-management
```

本仓库只包含工作流说明和配置，不包含企业微信账号、患者数据或智能表格数据。
